# Drowsiness Detection Workshop

Welcome! Everything you need for our workshop is already inside this folder.

---

##  Super Fast Setup (Pick Option A or Option B)

### Option A: The 1-Click Way (Easiest for Windows!)
Just double-click on **`start_workshop.bat`** inside this folder.
- It will automatically install the libraries and open Jupyter Notebook in your web browser. That's it!

---

### Option B: Using the Terminal (2 Minutes)

####  Windows (PowerShell or Command Prompt)
1. Open your terminal and go into this folder:
   ```powershell
   cd drowsiness-workshop
   ```
2. Install the required tools:
   ```powershell
   py -m pip install -r requirements.txt
   ```
3. Launch your notebook:
   ```powershell
   py -m notebook
   ```

####  macOS &  Linux (Terminal)
1. Open your terminal and go into this folder:
   ```bash
   cd drowsiness-workshop
   ```
2. Install the required tools:
   ```bash
   python3 -m pip install -r requirements.txt
   ```
3. Launch your notebook:
   ```bash
   python3 -m notebook
   ```

---

##  What to do once Jupyter opens:
1. In your browser, click on **`Drowsiness_Classification_Workshop.ipynb`**.
2. **Leave the code cells blank!** Don't worry about writing code yet.
3. Your instructor will teach you how to write the code and load `dataset_EAR_300.csv` step-by-step during the live session!
